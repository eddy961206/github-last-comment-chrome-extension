# Chrome 웹 스토어 제품 설명 — 한국어

## 이름
GitHub 마지막 댓글

## 짧은 설명
GitHub 이슈 및 Pull Request 목록에서 마지막 댓글 작성자, 작성 시각과 미리보기를 바로 확인합니다.

## 상세 설명
이슈를 하나씩 열지 않고도 마지막으로 누가 댓글을 남겼는지 확인할 수 있습니다.

지원되는 GitHub 이슈 및 Pull Request 제목 아래에 작은 정보를 추가하여 마지막 일반 댓글의 작성자와 시각을 표시하고, 목록을 벗어나지 않고 댓글 내용을 미리 볼 수 있습니다.

주요 기능:
- 마지막 댓글 작성자와 작성 시각 표시
- 마우스 오버, 키보드, 버튼을 통한 안전한 마크다운 미리보기
- 기본 언어는 영어이며 설정에서 한국어 선택 가능
- 시간대(기기, 서울, UTC), 아바타, 댓글 없는 항목 표시 설정
- GitHub 요청 감소를 위한 최근 결과 재사용, 일시정지 및 항목별 다시 시도
- 현재 GitHub 로그인 세션 사용. 개인 액세스 토큰 불필요
- 페이지 스타일 충돌을 피하는 Shadow DOM 배지, 라이트 및 다크 테마 지원
- 개발자 원격 통계 수집 없음
- 선택적 사용 횟수 통계는 기본 비활성화이며 브라우저에만 저장되고 내보내기 또는 삭제 가능
- 광고 없음, 사용자 데이터 판매 없음

이 확장은 요청된 기능 제공을 위해서만 GitHub 페이지를 처리합니다. 댓글 내용, 저장소 이름, 이슈 주소, GitHub 사용자 이름, 쿠키, 토큰, 로컬 사용 횟수를 개발자에게 전송하지 않습니다.

참고: GitHub 내부 페이지 및 타임라인 구조 변경 시 안전한 확인이 어려운 항목은 추측하여 표시하지 않고 조회 상태로 안내합니다. 일반 대화 댓글을 지원하며, 코드 줄 리뷰 댓글과 GitHub Enterprise 별도 도메인은 지원하지 않습니다.
