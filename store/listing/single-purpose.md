# Single purpose statement

Last Comment for GitHub has one narrow purpose: surface the most recent ordinary comment information for GitHub issues and pull requests directly in GitHub list views, including the author, timestamp, and an on-demand preview.

All extension functionality supports that purpose. Settings only control how that information is displayed, cached, localized, timed, or counted locally. Optional counters, diagnostics export, and cache controls exist solely to operate and troubleshoot that single list feature.
