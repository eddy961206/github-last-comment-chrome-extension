# Chrome Web Store product listing — English

## Name
Last Comment for GitHub

## Short description
See the latest GitHub issue or pull request comment author, time, and preview directly in list views.

## Detailed description
Stop opening every issue just to see who replied last.

Last Comment for GitHub adds a compact second line beneath supported GitHub issue and pull request titles. It shows the latest ordinary comment author and timestamp, and lets you preview the formatted comment without leaving the list.

Highlights:
- Latest comment author and timestamp at a glance
- Hover, keyboard, and button comment preview with sanitized Markdown rendering
- English interface by default; Korean available in Settings
- Time-zone control (device, Seoul, UTC), avatars, and zero-comment display options
- Result reuse to reduce GitHub requests, with pause and per-item retry
- Uses the existing GitHub sign-in; no personal access token required
- Shadow DOM badges that avoid page style conflicts, with light and dark theme support
- No developer telemetry
- Optional usage counters are disabled by default, remain local to the browser, and can be exported or deleted
- No advertising and no sale of user data

The extension processes GitHub pages only to provide the requested feature. It does not transmit comment content, repository names, issue URLs, GitHub usernames, cookies, tokens, or local usage counters to the developer.

Note: GitHub can change its internal page and timeline structures. If a result cannot be verified safely, the extension shows a lookup status rather than guessing. General conversation comments are supported; inline code review comments and GitHub Enterprise domains are not supported.
