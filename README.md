# Last Comment for GitHub

**Know who replied. Stay in the list.**

A standalone Manifest V3 Chrome extension for last-comment authors, exact timestamps, and Markdown previews on GitHub issue and pull request lists. English is the default; Korean is available in settings. No Tampermonkey or separate API token is required.

The initial implementation and store submission kit are being added to `main`. This repository is not a published Chrome Web Store listing. Publication requires the owner's developer account, final acceptance checks, disclosures, and review.
